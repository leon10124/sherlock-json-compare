Compare JSON without generated-field noise

Ignore exact timestamp paths. Compare unordered collections while keeping duplicate counts significant. Keep ordered mode for sequences.

Download the tested Windows ZIP

Start on Windows

  1. Download the ZIP from the release page and extract it.
  2. Double-click JSON-Compare.exe. Python is not required for this executable.
  3. Your browser opens a loopback address. Paste two JSON documents and compare.
  4. Keep the process running while using the browser. Close the local process to stop.

The executable is unsigned; platform security may display a warning or block it. Do not bypass organization security controls. Source code is available for review and running with Python 3.10+.

Try generated-field noise

{"updated":"2026-09-29","ids":[1,2]}
{"updated":"2026-09-30","ids":[2,1]}

Paste one object in each input. Ignore /updated and enable unordered arrays: the result is equal. Disable unordered arrays when sequence order matters. [1,1,2] and [1,2,2] remain different even in unordered mode.

Limits and privacy

This page is documentation, not an online comparator. The downloaded app processes JSON in memory on your own loopback server, without input logs. Do not paste credentials. Each document is limited to 256 KiB, 64 nesting levels and 10,000 nodes; at most 200 changes are shown. Duplicate object keys and non-finite numbers are rejected. Exact ignore paths match a location, not every field with the same name. Unordered mode applies to all arrays recursively. No JSON Patch compatibility is claimed.

This documentation page has no forms, analytics scripts, tracking pixels or external embeds. GitHub serves the page and may process technical access information under its privacy statement.
